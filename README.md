# Landing Gear Vibration Analysis — Boeing 737 Case Study

Vibration analysis of an aircraft landing gear system, using the Boeing 737 as a reference case study.

## Overview
This project analyzes the vibrational characteristics of a landing gear assembly, using Boeing 737 landing gear parameters as a representative case study to examine dynamic loading and resonance behavior during ground operations.

## Scope
- Landing gear structural/dynamic modeling
- Vibration mode identification
- Analysis of dynamic loads during taxi, takeoff, and landing conditions
- Case study benchmarking against Boeing 737 landing gear parameters

## Tools
- ANSYS (modal/vibration analysis)
- SolidWorks/CATIA (geometry)
- MATLAB (signal/vibration data processing)
